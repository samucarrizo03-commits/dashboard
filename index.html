Broker MQTT: test.mosquitto.org · Puerto TCP para dispositivos: 1883
Importante: una página web no puede abrir directamente una conexión MQTT TCP al puerto 1883. Por eso, este dashboard usa MQTT sobre WebSocket seguro (WSS) en el puerto 8081. El ESP32 u otro dispositivo puede conectarse al mismo broker usando MQTT TCP por el puerto 1883. Ambos deben publicar y suscribirse a los mismos tópicos.
